# Smart Pet Healthcare Monitoring System

**Senior Honors Experience (2026–2027)**  
St. Lawrence University

## Overview

An ongoing research and development project exploring an embedded pet-health monitoring system that collects physiological measurements and integrates them with an iOS application for visualization and analysis.

## Research Background

This project builds upon my undergraduate summer research conducted through a St. Lawrence University Research Fellowship in 2025.

During the summer fellowship, I developed an initial iOS application prototype focused on recording, managing, and displaying pet-health information. This work established the software foundation for my Senior Honors Experience.

In 2026–2027, I am extending the prototype toward an embedded monitoring system that integrates physiological sensors, microcontroller-based data collection, and cloud-based data management.

## Technologies

- **Mobile Development:** Swift, SwiftUI, Swift Charts
- **Embedded Hardware:** Raspberry Pi Pico 2
- **Sensors:** MAX30102, MAX30205
- **Cloud & Data:** Firebase, JSON
- **Microcontroller Programming:** MicroPython
